# USER_DOC — プレイヤー／評価者向けマニュアル

このドキュメントは、cub3D の遊び方と、自作マップ（`.cub` ファイル）を作成するためのルールをまとめたものです。実装と一致する内容のみを記載しています。

---

## 1. 起動

```
make
./cub3D <path/to/map.cub>
```

`maps/valid/` 配下に動作確認用のマップが用意されています。

```
./cub3D maps/valid/1.cub
./cub3D maps/valid/21x21_arena.cub
./cub3D maps/valid/enemy_line.cub
```

## 2. 操作

| キー | 動作 |
|---|---|
| `W` / `S` | 前進 / 後退 |
| `A` / `D` | 左右への平行移動 |
| `←` / `→` | 視点を左右に回転 |
| `1` | ピストルを装備 |
| `2` | フラッシュライト（懐中電灯）を装備 |
| `3` | 素手（移動が 1.3 倍速くなる） |
| `Space` | 射撃（ピストル装備時のみ。クールダウンあり） |
| `I` | UI（ミニマップ・収集進捗）の表示切替 |
| `O` | クロスヘアの表示切替 |
| `L` | 距離による陰影（シェード）の切替 |
| `Esc` / ウィンドウの × | 終了 |

> 上下矢印・Q・E は現状割り当てられていません。

## 3. ゲーム要素

- `4` で配置された **収集アイテム** に触れると獲得され、UI に進捗（`Collect: x / y`）が表示されます。全部集めると `GG !` の表示になります。
- `M` で配置された **敵** はプレイヤーの方角を向き、視界に入ると 5 秒間プレイヤーを追跡してきます。ピストルで撃って 10 ヒットさせると倒せます。
- `2` / `3` は通行不能な障害物として表示されます。

## 4. `.cub` ファイルの記述ルール

### 4.1 設定ヘッダ

ファイル前半に、画面解像度・テクスチャ・色を記述します。同じキーは **1 度だけ** 記述できます。

```
R 1920 1080                                # 解像度 (幅 高さ)

NO ./textures/wall/Wall_1.xpm              # 北向きの壁テクスチャ
SO ./textures/wall/Wall_2.xpm              # 南向きの壁テクスチャ
WE ./textures/wall/Wall_3.xpm              # 西向きの壁テクスチャ
EA ./textures/wall/Wall_4.xpm              # 東向きの壁テクスチャ

ST ./textures/wall/Wall_mossy.xpm          # 天井テクスチャ (任意)
FT ./textures/wall/Wall_tile.xpm           # 床テクスチャ (任意)

F 184,113,39                               # 床の色 R,G,B (テクスチャ未指定時のフォールバック)
C 51,198,227                               # 天井の色 R,G,B

OI ./textures/object/Object_barrel.xpm     # スプライト '2' (通行不可) のテクスチャ
OP ./textures/enemy/Enemy_1.xpm            # スプライト '3' (通行可)   のテクスチャ
OC ./textures/object/Object_star.xpm       # スプライト '4' (収集アイテム) のテクスチャ
```

サポートされる画像形式は `.xpm` のみです。

### 4.2 マップ本体

ヘッダの後にマップを記述します。マップは設定ヘッダの **最後** に置く必要があります。

使用可能な文字は以下です:

| 文字 | 意味 |
|---|---|
| `0` | 通行可能な床 |
| `1` | 壁（通行不可） |
| `2` | 通行不可な障害物（OI のテクスチャで描画される） |
| `3` | 通行可能な装飾オブジェクト（OP のテクスチャ） |
| `4` | 収集アイテム（OC のテクスチャ。触れると獲得） |
| `M` | 敵の出現地点 |
| `N` / `S` / `E` / `W` | プレイヤー初期位置と向き |
| 空白 | 描画されない領域 |

ルール:

1. プレイヤーのスタート地点 `N` / `S` / `E` / `W` は **最低 1 つ** 必要です。
2. マップは壁 `1` で囲まれている必要があります。隙間や開いた境界はパースエラーとなります。
3. マップの列数は、字句解析後にすべての行で一致している必要があります（空白を除いて）。
4. 1 セルはスペースで区切られています（例: `1 0 0 1`）。

### 4.3 解像度の制約

実行時、要求された解像度は内部で次の範囲にクリップされます。

- 最小: 848 × 480
- 最大: 1920 × 1080

これより大きな値を書いても、自動的に 1920×1080 にまで縮められます。

## 5. うまく動かないとき

- **`Error: invalid map.`** … `.cub` の構文か、マップの壁が閉じていない可能性があります。
- **`Error: failed to load texture(s).`** … テクスチャパスを `.cub` ファイルからの相対ではなく、**`cub3D` を起動するカレントディレクトリから** の相対で書く必要があります（例: リポジトリルートで `./cub3D maps/valid/1.cub` を実行する想定）。
- **画面が真っ黒** … テクスチャパスが間違っている、または XPM 以外の画像形式を指定している可能性があります。
